# Numpad Control backend

The cloud side of Numpad Control: the shared profile library and profile sync between
computers. It is open source under the [GNU Affero General Public License v3.0](LICENSE)
(AGPL), unlike the rest of the repository (GPL-3.0): anyone who runs a modified copy as
a service for others must publish their changes.

Nothing is here yet; it's planned for phase 4 of the plan
([`docs/plan-section-11-open-core.md`](../docs/plan-section-11-open-core.md)). The
official app uses the hosted instance; anyone can run their own copy on their own servers.
