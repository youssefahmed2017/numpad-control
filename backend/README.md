# NumpadPilot backend

The cloud side of NumpadPilot: the shared profile library and profile sync between
computers. Like the rest of the repository it is open source under the
[GNU General Public License v3.0](../LICENSE) (GPL-3.0).

Nothing is here yet; it's planned for phase 4 of the plan. The app will use a hosted
instance, and anyone can run their own copy on their own servers.
