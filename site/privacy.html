Privacy

Almost nothing, on purpose

Last updated October 27, 2026.

The NumpadPilot program

NumpadPilot reads the keys of the numpad you choose, so it can run the actions you set up. It collects nothing: no telemetry, no usage statistics, no account, and nothing you type ever leaves your computer.

  • Crash reports are only sent if you say yes in the dialog that appears after a crash. Yes opens a pre-filled GitHub issue in your browser, so you read everything before sending it. A report contains the error, where in the program it happened, the version and your operating system, with your user name and home folder taken out.
  • Updates: once a day the program asks GitHub whether a new version exists. GitHub sees that request, like any visit to a website.

This website

  • Visit counting uses GoatCounter: no cookies, no tracking across sites, and no personal data stored. It counts page views.
  • The waitlist stores your email, what you'd use NumpadPilot for and which computer it's for (if you say), through Formspree. It's used only to email you about NumpadPilot (the beta and the launch), never sold or shared.
  • Your colour and dark-mode choice are saved in your own browser, not sent anywhere.
  • Fonts and everything else are served from this site itself (hosted on GitHub Pages), with no calls to other font or ad services.

Your choices

To leave the waitlist or have your email deleted, reply to any NumpadPilot email or open an issue on GitHub (don't put your email address in a public issue: just ask, and we'll arrange it privately).
