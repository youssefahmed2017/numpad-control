Known limits

What it can't do, today

GNOME on Wayland

GNOME does not let programs read the focused window, so per-app profiles, Focus a window and Force-quit are not possible there. The other window actions go through GNOME's own shortcuts.

32-bit programs and administrator programs

They do not load the Windows keyboard hook, so the numpad's keys still type there (its actions still run). NumLock on the numpad still switches NumLock.

Games with strict anti-cheat

NumpadControl lets go of the numpad completely while such a game runs. It does not promise anything beyond that.

Window frames

The settings window and its dialogs sit in the desktop's own window frame, so their outer corners and shadow are the desktop's, not the website's. Everything inside the frame uses the website's sizes.

Windows is the newer side

Its installer and some actions are tested less than Linux's. Some cheap numpads also drop off USB on a weak port or cable; the kernel log shows it, and another port helps.
