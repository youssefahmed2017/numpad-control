Code signing policy

Who signs what, and how

Last updated November 3, 2026.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: the Windows installer is not signed yet, so Windows may show "Windows protected your PC". NumpadControl plans to use free code signing from SignPath Foundation. This page describes how that will work, and it will be updated when it starts.

What is signed

  • The Windows installer, NumpadControl-Setup-X.exe, built by GitHub Actions from the public repository (the build script is packaging/windows/build-installer.ps1). Nothing is signed that wasn't built there from that source.
  • Everything in the installer is open source: NumpadControl (GPL-3.0), and the third-party libraries it ships (Python, Qt for Python, and a few others, each under its own open licence). The keyboard hook DLL is compiled from numpadhook.c in the same build.
  • NumpadControl has no paid edition and no closed-source parts.

Who does what

  • Author and maintainer: Youssef Ahmed (youssefahmed2017).
  • Reviewer and approver: also Youssef Ahmed, as this is a one-person project. Every release is approved by hand before it is signed, and nothing is signed automatically.
  • Access to the repository and to the signing service is protected with multi-factor authentication.

What the program does

  • It reads the keys of the numpad you choose and runs the actions you set up. It can hold back that numpad's keys so they only run actions; on Windows it does so with a keyboard hook (Raw Input, no driver). An optional driver (Interception) is only installed if you ask for it.
  • It collects nothing and sends nothing without you saying so. See the privacy page.
  • It starts at login only if you leave that option on, and the uninstaller (Settings → Apps) removes it, its shortcuts and its start-at-login entry.

Reporting a problem

If you think a signed file is harmful or wasn't built from this source, please open an issue and it will be looked at straight away; if it's confirmed, the release is withdrawn and SignPath is told so the signature can be revoked.
