Install it

Install the engine

One command

The installer gets everything it needs and starts NumpadPilot at login. After that it keeps itself up to date.

Open PowerShell (as your normal user, not as administrator) and paste:

irm https://raw.githubusercontent.com/youssefahmed2017/numpad-pilot/main/install.ps1 | iex

Windows 10 or 11, 64-bit. It installs Python if needed. No driver and no administrator rights. Afterwards, look for the NumpadPilot icon in the tray.

Open a terminal and paste:

curl -fsSL https://raw.githubusercontent.com/youssefahmed2017/numpad-pilot/main/install.sh | bash

Arch, Debian/Ubuntu or Fedora (and their relatives). It asks you to press a key on your numpad to find it, and for your password once, to install packages and a rule that lets it read that numpad (and only that one).

Then

Make your first key

1

Open the settings

Windows: NumpadPilot Settings in the Start menu, or the tray icon's Edit settings file. Linux: NumpadPilot in your app menu. Without the app, this opens the settings file in your text editor.

2

Give a key an action

Every action and its options are listed in the README. Save the file: NumpadPilot picks it up by itself.

3

Check your numpad

Got an unusual numpad? This walks you through every key and tells you what works. In the numpad-control folder in your home folder:

.venv/bin/python -m numpadctl check # Linux .venv\Scripts\python -m numpadctl check # Windows
